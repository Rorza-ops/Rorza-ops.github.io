What I built

An attention-driven scene pipeline: detect relevant objects, segment the urban scene, then update a dynamic knowledge graph used for situational-awareness reasoning.

  • Detection with YOLOv8
  • Segmentation with SAM2
  • Vision-language descriptions (Qwen2.5-VL / Gemini)
  • Dynamic scene knowledge graph (DSKG) for memory and advice
